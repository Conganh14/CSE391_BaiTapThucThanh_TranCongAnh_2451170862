# Tier 0 - Component đầu tiên

Đây là project React hoàn chỉnh cho bài tập Tier 0.

## Cách chạy

1. Mở terminal trong thư mục `session_04_react_basics/exercises_v2/tier0-first-component`
2. Chạy `npm install`
3. Chạy `npm run dev`
4. Mở trình duyệt theo địa chỉ Vite cung cấp (mặc định `http://localhost:5173`)

## Nội dung

- `src/App.jsx`: component chính hiển thị `UserProfile` và `ProductInfo`
- `src/main.jsx`: điểm vào của ứng dụng React
- `src/style.css`: kiểu dáng cơ bản
