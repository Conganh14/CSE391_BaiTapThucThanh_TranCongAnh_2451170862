# Tier 2 - JSX Variables

Project demo cho bài Tier 2: dùng biến và điều kiện trong JSX.

## Chạy project

1. Mở terminal tại `session_04_react_basics/projects/tier2-jsx-variables`
2. Chạy `npm install`
3. Chạy `npm run dev`
4. Mở trình duyệt theo địa chỉ Vite cung cấp

## Nội dung

- `src/App.jsx`: chứa ví dụ `SimpleVariables`, `TernaryDemo`, `AndDemo`, `ListRendering`
- `src/main.jsx`: điểm vào React
- `src/style.css`: kiểu dáng đơn giản

## Thử nghiệm

- Quan sát dữ liệu hiển thị bằng `{}`
- Đổi giá trị của `isLoggedIn`, `stock`, `products` trong `src/App.jsx` để thấy thay đổi
- Mở console nếu cần, nhưng ở Tier 2 không cần hooks
